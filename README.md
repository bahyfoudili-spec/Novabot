# 🤖 بوت ديسكورد احترافي

بوت متكامل مبني بـ **discord.js v14** يحتوي على:

- 🎫 **نظام تذاكر** كامل (فتح/استلام/إغلاق + حفظ نسخة من المحادثة)
- ✅ **نظام توثيق** بزر تفاعلي
- 🛡️ **نظام إشراف**: طرد، حظر، إلغاء حظر، إسكات (Timeout)، إلغاء إسكات، إنذارات، حذف رسائل
- 📜 **نظام سجلات** (Logs) لأحداث الإشراف، الرسائل المحذوفة/المعدّلة، انضمام/مغادرة الأعضاء
- 👋 **نظام ترحيب** قابل للتخصيص
- 🎭 **رتب تلقائية** للأعضاء الجدد
- 🌐 **لوحة تحكم بسيطة** (Dashboard) تعرض إحصائيات مباشرة، محمية بكلمة مرور

جميع الأوامر والرسائل باللغة العربية، والبيانات تُخزَّن محلياً في ملف JSON بسيط (لا حاجة لقاعدة بيانات خارجية).


## ⚙️ خطوات التشغيل

### 1) تثبيت الحزم
```bash
npm install
```

### 2) إنشاء تطبيق البوت
1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. أنشئ تطبيقاً جديداً (New Application)
3. من تبويب **Bot**: فعّل الصلاحيات التالية (Privileged Gateway Intents):
   - `SERVER MEMBERS INTENT`
   - `MESSAGE CONTENT INTENT`
4. انسخ **Token** الخاص بالبوت
5. من تبويب **General Information** انسخ **Application ID** (هو نفسه CLIENT_ID)

### 3) إعداد متغيرات البيئة
انسخ `.env.example` إلى `.env` واملأ القيم:
```
DISCORD_TOKEN=التوكن_الخاص_بالبوت
CLIENT_ID=آيدي_التطبيق
GUILD_ID=آيدي_سيرفرك (اختياري أثناء التطوير لنشر أسرع)
DASHBOARD_PORT=3000
DASHBOARD_USER=admin
DASHBOARD_PASS=كلمة_مرور_قوية
```

### 4) دعوة البوت لسيرفرك
أنشئ رابط الدعوة من **OAuth2 > URL Generator**:
- Scopes: `bot`, `applications.commands`
- Permissions: `Administrator` (الأسهل)، أو صلاحيات محددة: إدارة الرتب، إدارة القنوات، طرد/حظر الأعضاء، إدارة الرسائل، إسكات الأعضاء

### 5) نشر أوامر السلاش
```bash
npm run deploy
```

### 6) تشغيل البوت
```bash
npm start
```
لوحة التحكم ستعمل تلقائياً على: `http://localhost:3000` (أو المنفذ الذي حددته)

## 🔐 ملاحظات أمان مهمة

- لا تشارك ملف `.env` أو التوكن مع أي أحد.
- غيّر `DASHBOARD_PASS` إلى كلمة مرور قوية قبل النشر.
- إذا نشرت البوت على استضافة عامة، ضع لوحة التحكم خلف HTTPS (مثلاً عبر Nginx أو Cloudflare Tunnel) لأن المصادقة الحالية Basic Auth بسيطة ومناسبة للاستخدام الداخلي/التطوير.
- تأكد أن رتبة البوت في السيرفر أعلى من الرتب التي يديرها (رتبة التوثيق، الرتبة التلقائية) حتى تعمل بشكل صحيح.

## 🛠️ التخصيص

- الألوان والفوتر الافتراضي للـ Embeds: `src/utils/embeds.js`
- تخزين البيانات: `src/utils/db.js` (ملف JSON بسيط — يمكن استبداله لاحقاً بقاعدة بيانات حقيقية مثل MongoDB أو SQLite)
- تصميم لوحة التحكم: `src/dashboard/views/index.ejs` و `src/dashboard/public/style.css`
